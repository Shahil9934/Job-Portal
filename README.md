# Job-Portal
Full-featured Job Portal with job search, filters, applications, authentication, recruiter dashboard, and application tracking.
The application allows candidates to search and apply for jobs, save jobs, manage their profiles, and track applications. Recruiters can post jobs, manage job listings, review applicants, and update application statuses.

Features
 Candidate Features
User registration and login
Browse available jobs
Search jobs by keyword
Filter jobs by location, experience, and job type
View detailed job information
Apply for jobs
Save/unsave jobs
View applied jobs
Track application status
Manage user profile
Upload resume

 Recruiter Features

Recruiter authentication
Recruiter dashboard
Create and post new jobs
Edit and delete job postings
Manage active job listings
View applicants
View candidate details
Update application status
Track recruitment activity

Tech Stack

React.js – Frontend UI
TypeScript – Type safety
Redux Toolkit – Global state management
RTK Query – API calls and caching
React Router – Client-side routing
Tailwind CSS – Responsive UI
Axios / REST API – API communication
React Hook Form – Form handling
Zod / Yup – Form validation
JWT – Authentication
